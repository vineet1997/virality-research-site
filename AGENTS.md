# Virality Research public site

This repository contains only approved public website material. Do not copy raw PDFs, extracted passages, local file paths, private acquisition details, internal review notes, agent outputs, or unapproved evidence cards here.

The source catalogue is a public metadata snapshot. “Evidence reviewed” means source-level verification; it is never shorthand for a published cross-source conclusion.

Before changing counts or research status, update the public snapshot deliberately and check that Home, Research, and Sources agree. Preserve the distinction between causal evidence, correlational evidence, practitioner frameworks, and anecdotes.
